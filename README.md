# Neural-operator surrogates for outdoor acoustics (LEE–FDTD)

This repository provides training scripts accompanying the paper “Towards Neural-operator Surrogates for Outdoor Acoustics using Parameterized Wind Profiles and Terrain” (JASA submission).

We learn operators that map parameterized wind profiles $U(z)$ and/or terrain profiles $h(x)$ to complex acoustic pressure fields on a fixed 2D region-of-interest (ROI) grid:

- $G_U: U \mapsto p(x,z)$
- $G_h: h \mapsto p(x,z)$
- $G_{U,h}: (U,h) \mapsto p(x,z)$

All models predict two output channels $[p_{\mathrm{re}},\, p_{\mathrm{im}}]$ on the ROI grid, SPL is derived by postprocessing.

## Data and representation (paper-consistent)

### ROI grid and complex pressure
Training data are generated by a 2D LEE finite-difference time-domain (FDTD) solver and stored as a complex phasor on the ROI grid using two channels:
- `pre = Re(P)`
- `pim = Im(P)`

### Terrain features on a fixed grid
Terrain is represented on the fixed ROI grid using a height-above-ground coordinate:

$$
\eta(x,z)=z-h(x)
$$

and supervision/evaluation is restricted to the air region using the mask:

$$
m(x,z)=\mathbf{1}[\eta(x,z)\ge 0].
$$

When used as a feature, $\eta$ is scaled to $\eta_{\mathrm{norm}}$. Spatial coordinates are normalized to $[-1,1]$.

### Wind features on a fixed grid
Wind is provided as a vertical profile $U(z)$ and broadcast onto the ROI grid as $U_{\mathrm{grid}}(x,z)=U(z)$, then scaled to $U_{\mathrm{norm}}$ by a constant factor.

### Direct vs residual targets (optional)
Scripts may support:
- Direct: $y(x,z)=p(x,z)$
- Residual: $y(x,z)=\Delta p(x,z)=p(x,z)-p_0(x,z)$, with reconstruction $p=\Delta p + p_0$

The fixed baseline $p_0$ can be obtained once from the solver using no-wind $U(z)\equiv 0$ and flat ground $h(x)\equiv 0$.

## What each script trains (FNO)

Input channel conventions (as used in the paper):

- Wind-only: $[U_{\mathrm{norm}},\, \tilde{x},\, \tilde{z}]$
- Terrain-only: $[\eta_{\mathrm{norm}},\, m,\, \tilde{x},\, \tilde{z}]$
- Joint wind+terrain: $[U_{\mathrm{norm}},\, \eta_{\mathrm{norm}},\, m,\, \tilde{x},\, \tilde{z}]$

### Scripts

- `train_fno_wind_coords.py`  
  Trains $G_U$ (wind-only) using wind-on-grid + normalized coordinate channels.

- `train_fno_terrain_eta_mask.py`  
  Trains $G_h$ (terrain-only) using $\eta_{\mathrm{norm}}$, air mask $m$, and coordinates, losses/metrics are masked to the air region.

- `train_fno_terrain_eta_mask_coords.py`  
  Terrain-only variant (same “house style” as the others), with explicit coordinate channels and the same masking conventions.

- `train_fno_joint_wind_terrain_eta_mask.py`  
  Trains $G_{U,h}$ (joint) using wind + terrain features + mask + coordinates.

## Running (minimal)

Each script has a `CFG` block near the top. To run on the included samples:

1) Set `CFG["data_root"] = "data_sample"` (or point it to your own dataset folder).
2) Run the script, e.g.
```bash
python train_fno_wind_coords.py
```

Scripts typically write:
- `checkpoints/` (trained weights)
- `results/` (evaluation summaries as JSON)
- `splits/` and/or cached statistics (depending on configuration)
